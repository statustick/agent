# Security

Please report a security problem in the agent privately to **hello@statustick.com** with "Security" in the subject, not in a public issue. Include the agent version (the first line the agent logs), what you did and what happened.

We answer within 3 working days, keep you informed while we fix it, and credit you in the changelog if you want. Fixes for security problems can raise the minimum agent version without the usual 30-day notice.

What the agent may do and send, and the threats we designed against, are in [docs/agent-security.md](docs/agent-security.md).
