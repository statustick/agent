# Security

Please report security problems privately, not in a public issue: use [Report a vulnerability](https://github.com/statustick/agent/security/advisories/new) on GitHub, or email **hello@statustick.com** with "Security" in the subject. Include the agent version, what you did and what happened.

We reply within 3 working days and keep you informed while we fix it. If you like, we credit you in the changelog. A security fix can raise the minimum agent version without the usual 30-day notice.

What the agent does and sends: [docs/agent-security.md](docs/agent-security.md).
